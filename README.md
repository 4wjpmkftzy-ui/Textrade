# Textrade

大学生同士で中古の教科書を売買するためのマッチングサイトです。
運営は「場」を提供するだけで、代金のやり取りや受け渡しは当事者同士で行います。

## 使っている技術

| 役割 | 技術 |
|---|---|
| 画面・サーバー処理 | Next.js(TypeScript) |
| デザイン | Tailwind CSS |
| 会員管理・データベース・画像保存 | Supabase(予定) |
| 公開 | Vercel(予定) |

## 手元で動かす方法

```bash
npm install     # 必要な部品をダウンロード(最初の1回だけ)
npm run dev     # 開発用サーバーを起動
```

起動後、ブラウザで http://localhost:3000 を開くとサイトが表示されます。

## フォルダ構成(主なもの)

```
src/
  app/          … ページ(URLごとにフォルダが対応)
  components/   … 複数のページで使い回す部品(ヘッダー、フッターなど)
```
