# Textrade 開発計画と決定事項

作業を別のセッションに引き継いでも迷わないよう、決まったことをここに記録します。

## 進め方の約束
- オーナーはプログラミング未経験。各ステップで何をしているか、初心者にもわかる日本語で説明する
- 作業の区切りごとに Git でコミットし、GitHub(`4wjpmkftzy-ui/Textrade`)へプッシュする
- セキュリティ(個人情報が他人に見えないこと)を最優先にする
- スマホで見やすいデザインにする

## サービスの前提
- 名前:**Textrade**
- 学生同士の中古教科書マッチング。運営は場を提供するだけ
- 代金:**PayPay送金などで当事者同士が直接やり取り**(運営はお金に触れない=「形A」)
  - 出品時に支払い方法(PayPay/現金/応相談、複数可)を選べる
  - 受け取り時に支払うことをサイト上で推奨する
- 受け渡し場所はサイト側で指定・案内しない
- 大学のロゴ・校章は使わない。大学名は所属を示す目的でのみ表示
- フッターに「各大学とは関係のない、学生が運営する独立したサービスです」
- メールは登録確認など必要なものだけ。宣伝メール機能は作らない
- 将来:オンライン決済+手数料を追加できる設計(`transactions` テーブルを用意済み)

## 決定事項
- 表示名:**ニックネームのみ**(他の利用者に見えるのはニックネームと大学名だけ)
- 本の状態:新品同様 / 書き込みなし / 書き込み少し / 書き込み多い + マーカー・線引きの有無
- 開示できる連絡先:PayPay ID、LINE ID、連絡用メール、自由記入欄
  (ログイン用メールアドレスは開示対象にしない)
- 最初の対応大学:立命館大学(`ed.ritsumei.ac.jp`)
- 通報機能を追加する

## 技術構成
| 役割 | 技術 |
|---|---|
| 画面・サーバー処理 | Next.js 16(App Router、TypeScript、`src/` 構成) |
| デザイン | Tailwind CSS v4 |
| 会員管理・DB・画像保存 | Supabase(東京リージョン) |
| 公開 | Vercel(Hobby。商用化したら Pro か Cloudflare へ) |
| メール送信 | Resend(独自ドメイン取得後) |

- Next.js 16 は学習データと仕様が異なる部分がある。`node_modules/next/dist/docs/` を確認してから書く(AGENTS.md 参照)
- 写真はサーバー側で WebP に再変換し、位置情報(EXIF)を削除・圧縮してから保存する
- 写真の置き場は将来 Cloudflare R2 に移せるよう、保存処理を1か所にまとめる
- Supabase 無料プランには自動バックアップがないため、公開前に定期バックアップの仕組みを用意する

## 認証の流れ
1. 大学メール+パスワード+ニックネームで登録(未対応ドメインはDB側で拒否)
2. 確認メールのリンクで認証 → `user_private.university_verified_at` が記録される
3. 任意で、ログイン用メールを個人メールに変更(Supabaseのメール変更機能。確認メールあり)
4. 所属大学は最初の大学メールで決まり、ログイン用メールを変えても変わらない

```bash
cp -r supabase /tmp/pgt && chmod -R a+rwX /tmp/pgt   # postgres ユーザーが読める場所へ
su postgres -c "bash /tmp/pgt/supabase/tests/run_local.sh"
```
